# Profile views counter

A tiny Cloudflare Worker that counts views of the GitHub profile and returns a badge drawn
like the README's link buttons: cream or dark tile, ink border, hard shadow, a terracotta
eye, and the count in Space Mono. It runs free on the Workers Free plan.

| URL | What it does |
| --- | --- |
| `/views.svg?theme=light` or `?theme=dark` | Counts one view and returns the badge |
| `/peek.svg?theme=light` or `?theme=dark` | Returns the badge without counting, for checking |

The count lives in one Durable Object, so simultaneous views can't overwrite each other.
Responses are marked uncacheable so GitHub's image proxy fetches a fresh count each time.
It counts page loads, not unique people, and includes your own visits.

## Deploy (about 5 minutes, once)

You need [Node.js](https://nodejs.org) 18 or newer and a free
[Cloudflare account](https://dash.cloudflare.com/sign-up).

1. In a terminal, go to this folder and install the tools:

   ```bash
   cd counter
   ```

   ```bash
   npm install
   ```

2. Sign in to Cloudflare (this opens your browser):

   ```bash
   npx wrangler login
   ```

3. Deploy:

   ```bash
   npx wrangler deploy
   ```

   The last lines print the Worker's address, like
   `https://profile-views.<your-subdomain>.workers.dev`. If Cloudflare asks you to pick a
   `workers.dev` subdomain first, choose one and run the deploy again.

4. Check it: open `https://profile-views.<your-subdomain>.workers.dev/peek.svg` in a browser.
   You should see the badge with a count of 0.

Then add it to the profile README with the light and dark versions:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://profile-views.<your-subdomain>.workers.dev/views.svg?theme=dark">
  <img src="https://profile-views.<your-subdomain>.workers.dev/views.svg?theme=light" height="48" alt="Profile views">
</picture>
```

## Changing it

- The badge's look is in `src/badge.js`; the counting is in `src/index.js`.
- `src/font.js` is generated by `scripts/build_cards.py` (Space Mono Bold, subset to the
  counter's characters). Rebuild the cards to regenerate it.
- Run it locally with `npx wrangler dev`, then open `http://localhost:8787/views.svg`.
- Redeploy after a change with `npx wrangler deploy`. The count is kept.
